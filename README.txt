================================================================
  پروژه ایرانسل - پودمان 5 (سوالات 1 و 2)
================================================================

ساختار پوشه‌ها:
  Database\           -> فایل irancell.accdb و راهنمای Access
  IrancellApp\        -> پروژه Visual Studio (Windows Forms)

----------------------------------------------------------------
سوال 1 - پایگاه داده Access
----------------------------------------------------------------
فایل: Database\irancell.accdb
جدول: Customer

فیلدها:
  mobileNo   (کلید اصلی)
  firstName
  lastName
  fatherName
  birthdate
  meliCode

برای ساخت دستی در Access فایل راهنمای_سوال1.txt را ببینید.

----------------------------------------------------------------
سوال 2 - فرم Visual Studio
----------------------------------------------------------------
1. فایل IrancellApp.sln را در Visual Studio باز کنید
2. F5 بزنید (Run)
3. TextBox ها به جدول Customer وصل هستند
4. DataGridView کل جدول را نشان می‌دهد
5. در بخش جستجو شماره همراه را تایپ کنید -> فیلتر می‌شود

نیازمندی:
  Microsoft Access Database Engine (ACE OLEDB 12.0)

----------------------------------------------------------------
نکته برای ارائه:
  اگر دیتابیس خالی است، چند رکورد نمونه از Access اضافه کنید
  تا جستجو را نشان دهید.
